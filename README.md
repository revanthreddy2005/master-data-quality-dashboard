# Master Data Quality Dashboard

## Project Overview

A Power BI dashboard designed to monitor and analyze master data quality across **Customers, Products, Pricing, and Vendors**.

The project focuses on identifying data-quality issues, analyzing issue patterns, and presenting business insights through interactive visualizations.

## Objective

* Monitor master data quality
* Identify recurring data-quality issues
* Analyze issues across different master-data areas
* Track overall issue rates
* Present findings through an interactive dashboard

## Tools Used

* **Power BI**
* **Power Query**
* **Microsoft Excel**
* **DAX**

## Dashboard Metrics

* **6,000** total records reviewed
* **726** issues identified
* **12.1%** overall issue rate

## Dashboard Features

* Issues by Master Data Area
* Data Quality Issues by Category
* Top Data Quality Issues
* Interactive Master Data filter
* Interactive Issue Category filter
* Key Findings section

## Key Findings

* Consistency issues represent the largest issue category.
* Category Standardization and Vendor Name Standardization are the two highest-volume issue types.
* 726 issues were identified across 6,000 records reviewed, resulting in a 12.1% overall issue rate.
